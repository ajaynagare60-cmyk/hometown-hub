\# Hometown Hub — Project Documentation



\## 1. Project Overview



Hometown Hub is a digital community platform designed to connect people

with their hometown and local communities.



\## 2. Technology Stack



\### Frontend

\- React

\- JavaScript

\- Vite

\- HTML

\- CSS



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- JWT Authentication

\- bcryptjs



\## 3. Main Features



\- User Registration and Login

\- Community Management

\- Posts

\- Comments

\- Likes

\- Events

\- Notifications

\- Admin Dashboard

\- Moderator Dashboard

\- Pandit Registration
